# Publicar no GitHub

O nome sugerido para o repositório é `projeto-otimizacao-trabalho-igor`.

1. Na sua conta `Dev-YuriCardoso`, crie um repositório vazio com esse nome. Não marque a opção para adicionar README, licença ou `.gitignore`, pois esses arquivos já estão nesta pasta.
2. Extraia este ZIP e abra um terminal dentro da pasta `projeto-otimizacao-trabalho-igor`.
3. Execute:

```bash
git init
git add .
git commit -m "Entrega AV2 - otimizacao de deteccao de duplicatas"
git branch -M main
git remote add origin https://github.com/Dev-YuriCardoso/projeto-otimizacao-trabalho-igor.git
git push -u origin main
```

O histórico inicial ficará associado ao usuário autenticado no seu terminal. Para evidenciar a participação de todos os integrantes, cada pessoa deve fazer commits próprios, com suas alterações, em vez de compartilhar as credenciais de uma única conta.
